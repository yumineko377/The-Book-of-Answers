# 答案之书 · 项目说明

## 📖 项目简介

答案之书是一个纯静态的互动网页，用户可以默念自己的问题，点击书本翻页，获得一个随机或指定的答案。

## 🎨 设计风格

- **配色方案**：紫色调 (#715fa4 #a791c0 #c9b9d2) + 暖黄 (#ffe5c8) + 淡蓝 (#aecadf)
- **视觉风格**：3D书本效果 + 翻页动画 + 动态光斑背景
- **字体选择**：
  - 标题：Noto Serif SC（中文衬线）+ Cormorant Garamond
  - 正文：Noto Sans SC（中文无衬线）
  - 代码：JetBrains Mono

## 📁 文件结构

```
F:\其他的\网页\答案之书\
├── index.html      # 主页面（HTML5）
├── styles.css      # 样式表（纯CSS）
├── script.js       # 交互逻辑（Vanilla JS）
├── answers.json    # 答案数据（500条）
└── answers.txt     # 原始数据
```

## 🚀 如何使用

### 方法1：直接打开
双击 `index.html`，直接在浏览器中打开

### 方法2：本地服务器（推荐）
```bash
# Python 3
cd F:\其他的\网页\答案之书
python -m http.server 8000

# 然后访问 http://localhost:8000
```

### 方法3：部署到服务器
将所有文件上传到任何静态网站托管服务：
- GitHub Pages
- Vercel
- Netlify
- 自己的服务器

## ⌨️ 键盘快捷键

| 按键 | 功能 | 说明 |
|-----|-----|-----|
| `Space` | 随机翻页 | 仅在封面页面有效 |
| `0-9` | 快速输入 | 自动聚焦到页码输入框 |
| `Enter` | 确认翻页 | 输入页码后按回车 |
| `Escape` | 返回封面 | 仅在答案页面有效 |

## 🔧 技术栈

纯前端，无后端，无框架依赖：
- **HTML5** - 语义化标签 + SEO
- **CSS3** - 3D变换 + 关键帧动画 + CSS变量
- **Vanilla JS** - 异步加载 + 事件处理 + 触摸支持
